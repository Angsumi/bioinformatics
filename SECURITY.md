# Security Policy

## Supported Versions

The latest commit on the `main` branch is actively maintained and supported.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security vulnerability in this project (e.g. cross-site scripting in interactive calculators or manifest exporters), please do not open a public issue. Instead, report it privately to the project maintainer via GitHub or email at `71340575+Angsumi@users.noreply.github.com`.
