🧩 Predicted Aligned Error (PAE) Matrix Explainer

Matrix Concept

The PAE matrix measures expected position error (in Ångströms) at residue $y$ when the predicted and true structures are aligned on residue $x$. Low error (dark green) indicates rigid relative orientation; high error (light yellow/white) indicates flexible hinge motions or independent domains.

Key Rule: High pLDDT does NOT guarantee rigid inter-domain docking. Always evaluate the off-diagonal squares in the PAE plot before concluding whether two domains or multimer subunits bind stably.

0. Deep Learning Architecture (Evoformer & IPA)

AlphaFold2 transforms primary sequences and homologous alignments using the Evoformer (which exchanges co-evolutionary residue pair information) and the Invariant Point Attention (IPA) module (which optimizes rigid 3D geometric transformations directly in Euclidean space without templates).

colabfold_batch \
  --num-recycle 3 \
  --amber \
  --use-gpu-relax \
  targets.fasta \
  predictions_out/

5. Amber Force Field Energy Relaxation

Resolves steric clashes and unphysical bond angle overlaps in side-chains using gradient descent energy minimization in the Amber99SB force field.

6. Confidence Metric Extraction (pLDDT, pTM, ipTM)

For complexes, evaluate the combined interface score: $\text{Model Score} = 0.8 \times \text{ipTM} + 0.2 \times \text{pTM}$. Scores $> 0.75$ signify high confidence interaction.

PYTHON
import json

with open("predictions_out/target_scores_rank_001.json") as f:
    scores = json.load(f)

print("Mean pLDDT:", sum(scores['plddt']) / len(scores['plddt']))
if 'iptm' in scores:
    print(f"pTM: {scores['ptm']:.3f} | ipTM: {scores['iptm']:.3f}")

9. ESMFold Ultra-Fast Protein Language Modeling

ESMFold by Meta AI predicts 3D structures 60x faster than AlphaFold directly from single sequences without needing multiple sequence alignments.

PYTHON
import torch
import esm

model = esm.pretrained.esmfold_v1()
model = model.eval().cuda()

sequence = "MKTIIALSYIFCLVFADYKDDDDK"
with torch.no_grad():
    output = model.infer_pdb(sequence)

with open("esmfold_result.pdb", "w") as f:
    f.write(output)
