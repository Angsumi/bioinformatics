# Bioinformatics & QIIME 2 Interactive Learning Lab

An interactive, production-grade learning laboratory and workflow guide for 16S, 18S, and ITS marker-gene amplicon data science using **QIIME 2**.

## 🌐 Live Webpage
- Hosted on GitHub Pages: **[https://angsumi.online/qiime2](https://angsumi.online/qiime2)**
- Direct Repo Pages: **[https://angsumi.online/bioinformatics/](https://angsumi.online/bioinformatics/)**

## 🧪 Key Features
- **Interactive DADA2 Truncation & Overlap Calculator**: Visual feedback ensuring $\ge 20$ bp read overlap.
- **Rarefaction Depth Advisor**: Dynamic sample loss vs sequencing depth trade-off calculation.
- **Interactive FASTQ Manifest Generator**: Auto-detects local FASTQ files, extracts sample IDs, and exports compliant `manifest.tsv`.
- **Sample Metadata Builder (#q2:types compliant)**: Live raw TSV preview, validation, and 1-click clipboard export.
- **Explain Cards (`💡 Explain`)**: Hover cards and modals across every pipeline block explaining functions, parameters, biological rationale, and pitfalls.
- **Live Parameter Customizers**: Synchronize experimental variables (primers, metadata columns, depths) across all commands in real time.
- **Three Decision Trees**: Step-by-step decision guides for denoising, classifier selection, and beta diversity metrics.
